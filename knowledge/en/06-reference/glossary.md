# Glossary

| Term | Meaning |
|---|---|
| **ATB** | Attacking the Batter. Fielders very close to the batter. See [Field Setting](../04-tactics/field-setting.md). |
| **Ability** | A 0-100 score for how fresh a player's training is. It wears off after matches. [Training](../05-progression/training.md). |
| **All-rounder** | A player who is good at both batting and bowling. |
| **Anti-snipe** | Signing Market rule: offers in the last 2 minutes of a decision window extend the deadline a little. |
| **Auto Build** | Playing XI button that picks the best valid XI and bowling order for you. |
| **Autoplay** | A bot that plays for your team when you are offline or when you switch it on. |
| **Balance** | Your coin balance. Also used for the amount reserved by offers. |
| **Batting level / Bowling level** | A player's batting or bowling rating from 0 to 100. |
| **Bench / Reserve** | Squad players not in the Playing XI. |
| **Championship** | The season-long tournament that crowns the champion. |
| **Decision window** | A 5-20 minute sealed-bid period when rivals want the same free agent. |
| **Dot ball** | A ball with no runs. |
| **Focus Boost** | A temporary rating boost (up to +1.5) from Match Preparation. |
| **Formation** | The balance of batsmen, all-rounders and bowlers in your squad, for example 5 · 2 · 4. |
| **Free agent** | A player with no team, available in the Signing Market. |
| **Free hit** | The ball after a no-ball. Only a run-out can dismiss the batter. |
| **Heat** | How contested a decision window is (low to fierce). |
| **Home boost** | A rating bonus for players from the league's home country. |
| **IC** | Inner Circle. The 30-yard fielding ring. |
| **Legend** | A special, highly priced player. Leagues may limit how many play together. |
| **Lower / Middle / Top order** | Batting position zones: 8-11, 4-8 and 1-4. |
| **MOTM** | Man of the Match. |
| **NP** | Normal Play, overs 4-10. Also the name of the NP1-NP9 fielding presets. |
| **NRR** | Net run rate, used to separate teams level on points. |
| **OC** | Outer Circle. Deep boundary fielders. |
| **OVR** | A player's overall rating, 0-100. |
| **Performance points** | Points earned in matches and spent on training. |
| **Pitch type** | Flat, Green, Dusty, Slow or Bouncy. [Stadiums and pitches](../04-tactics/stadiums-and-pitches.md). |
| **Playing XI** | The 11 players selected for a match. |
| **Pool (A-E)** | Quality tier of players. Teams have a quota per pool. [Pool quotas](../02-market/pool-quotas.md). |
| **PP** | Powerplay, overs 1-3. Also the name of the PP1-PP9 fielding presets. |
| **Preset** | A saved fielding arrangement for the Powerplay or Normal Play. |
| **Quick Match** | A fast one-off match against a bot. |
| **Quota** | How many players of each pool your team can hold. |
| **Retention** | End-of-season stage where you choose which players to keep. |
| **Scout** | A Signing Market tab that suggests what your squad needs. |
| **Series** | A short head-to-head tournament. |
| **Signing Market** | Where you sign free agents. |
| **Spinner** | The wheel that decides each ball. |
| **Super Over** | A one-over-each tie-breaker. |
| **Tactical Balance** | A 12-criteria score for how well-rounded your XI is. |
| **Watchlist** | Players you have starred to be notified about. |
